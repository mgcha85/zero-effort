# Domestic Community & Cafe Viral Copy Pack (국내 커뮤니티 바이럴 카피팩)

네이버 카페, 디시인사이드, 블라인드, 오픈채팅방 등에 자연스러운 정보 공유(팁/자랑) 형태로 배포할 수 있는 타겟별 카피입니다.

---

## 1. 유럽 여행 / 유학 커뮤니티 (네이버 카페 '유랑', 유럽 여행 오픈채팅)
- **타깃 도구**: 솅겐 계산기 (`https://schengen.minitoolbox.dev`)
- **글 제목**: `[정보] 유럽 여행 솅겐 90/180일 계산기 광고/가입 없는 사이트 공유합니다`
- **본문 내용**:
```text
안녕하세요!

유럽 장기 여행이나 교환학생, 워홀 준비할 때 제일 골치 아픈 게 솅겐 조약 90일 계산이잖아요 ㅠㅠ
앱스토어 앱들은 결제 유도하고, 기존 웹사이트들은 광고가 너무 많아서 불편해서
제가 깔끔하게 쓰려고 브라우저에서 바로 계산되는 웹툴을 만들었습니다.

👉 https://schengen.minitoolbox.dev (또는 https://minitoolbox.dev)

- 입출국 날짜만 넣으면 180일 롤링 윈도우 기준으로 남은 체류 가능 일수를 자동 계산해줍니다.
- 비행기표 예약 전 최대 출국 가능일 확인할 때 편합니다.
- 회원가입 없고, 여행 일정이 서버로 저장되지 않고 본인 폰/브라우저에만 남아서 안전합니다.

유럽 여행 준비하시는 분들께 도움 되었으면 좋겠습니다!
```

## 2. 독일 유학 / 워홀 커뮤니티 (베를린리포트, 독일 유학 카페)
- **타깃 도구**: 독일 안멜둥 서류 작성기 (`https://anmeldung.minitoolbox.dev`)
- **글 제목**: `독일 안멜둥(거주지등록) 서류 독일어 몰라도 작성하는 무료 툴 만들었습니다`
- **본문 내용**:
```text
독일 처음 오셔서 Bürgeramt 테어민 잡고 안멜둥 서류(Anmeldung bei einer Meldebehörde) 쓸 때
독일어 서식이라 칸마다 뭘 적어야 할지 난감하셨던 분들 많으실 겁니다.

한국어 안내 보면서 입력하면 독일 관청 제출용 규격 PDF로 바로 만들어주는 도구입니다.

👉 https://anmeldung.minitoolbox.dev

- 개인정보(여권번호, 생년월일, 이전 주소 등)가 서버로 절대 업로드되지 않고 100% 브라우저 메모리 안에서만 처리됩니다.
- 입력 후 [PDF 다운로드] 누르면 관청 제출 양식 그대로 출력됩니다.
- 로그인/결제 전혀 없이 무료입니다.

독일 정착 준비하시는 분들 유용하게 쓰세요!
```

## 3. 취업 준비 / 공공기관 서류 제출 (취뽀, 독취사, 뽐뿌, 클리앙)
- **타깃 도구**: 제로업로드 미디어 툴 & PDF 도구 (`https://media.minitoolbox.dev`, `https://pdf.minitoolbox.dev`)
- **글 제목**: `정부24 증명사진 규격 맞추기 / PDF 병합 서버 업로드 없이 브라우저에서 끝내는 팁`
- **본문 내용**:
```text
이력서나 정부24 서류 제출할 때 사진 용량 제한(100KB 이하)이나 3x4cm 규격 맞추기 까다롭고,
금융거래내역서나 주민등록등본 PDF 합칠 때 외국 사이트(ilovepdf 등)에 내 주민번호 적힌 파일 올리기 찝찝하셨죠?

서버로 파일 업로드 전혀 없이 내 컴퓨터 브라우저 안에서만 처리되는 무료 도구 모음입니다.

👉 사진 규격/용량 조절: https://media.minitoolbox.dev
👉 PDF 합치기/나누기: https://pdf.minitoolbox.dev

- 파일이 외부 서버로 1바이트도 전송되지 않아서 개인정보/금융정보 유출 걱정이 없습니다.
- 개발자 도구(F12) 네트워크 탭 열어보셔도 업로드 트래픽 전혀 안 일어납니다.
- 설치나 로그인 없이 바로 사용 가능합니다.
```
